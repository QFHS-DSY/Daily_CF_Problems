# Codeforces 数据结构练习题单

适合刚学完线段树后按顺序练习。难度为 CF rating。

## 线段树

| 题目 | 难度 | 训练点 |
| --- | ---: | --- |
| [1234D - Distinct Characters Queries](https://codeforces.com/problemset/problem/1234/D) | 1700 | 区间字符集合、单点修改 |
| [339D - Xenia and Bit Operations](https://codeforces.com/problemset/problem/339/D) | 1800 | 交替 OR/XOR |
| [52C - Circular RMQ](https://codeforces.com/problemset/problem/52/C) | 1900 | Lazy propagation、环形区间 |
| [380C - Sereja and Brackets](https://codeforces.com/problemset/problem/380/C) | 1900 | 括号信息合并 |
| [474F - Ant colony](https://codeforces.com/problemset/problem/474/F) | 1900 | GCD 与最小值查询 |
| [920F - SUM and REPLACE](https://codeforces.com/problemset/problem/920/F) | 2000 | 区间修改、势能分析 |
| [438D - The Child and Sequence](https://codeforces.com/problemset/problem/438/D) | 2100 | 区间取模剪枝 |
| [242E - XOR on Segment](https://codeforces.com/problemset/problem/242/E) | 2400 | 位拆分、区间 XOR 修改 |

推荐顺序：`1234D -> 339D -> 52C -> 380C -> 474F -> 920F -> 438D -> 242E`
